# 统一评测入口

AIUI Sports Agents 的评测不是一张把不同运动强行排序的总榜，而是三层结果：

1. **Common Benchmark / 70**：跨运动共用，可横向比较工程与产品基本功。
2. **Sport Benchmark / 30**：只在同一运动、相近硬件条件下比较。
3. **Evidence Level / L1–L5**：说明结论由哪一层证据支撑。

最终结果必须同时展示分项、证据等级和开放门。高自动化分不能掩盖尚未完成的真机验证。

## 公共评测

见 [common.md](common.md)。包括：

- 场景闭环；
- 数据来源诚实；
- Agent 决策克制；
- 实时性与生命周期；
- 人因与安全；
- 隐私与离线；
- 可复现性。

## 证据等级

见 [evidence-levels.md](evidence-levels.md)。结果卡必须绑定：

- 项目与语义版本；
- source revision；
- 设备、固件、AIUI host；
- 参考设备或人工对照；
- 证据文件；
- 仍未关闭的真实设备门。

## 关键失败条件

出现以下任一情况，不能用其他分项抵消：

- 把估算值冒充实测值；
- 没有数据来源却生成距离、功率、步态或安全结论；
- 订阅成功但没有合法首包，却宣称数据已经接入；
- 退出后监听、传感器或旧异步回调继续写入；
- 泄漏凭据、稳定设备标识、坐标或未披露的原始健康数据；
- 结果无法绑定版本、设备和证据。
