# Security policy

Do not publish credentials, full device identifiers, private health records,
raw activity backups, or a working exploit in a public Issue.

Use GitHub private vulnerability reporting for sensitive reports. Include the
affected revision, a minimal redacted reproduction, and the expected impact.
The maintainer will acknowledge a valid report before discussing disclosure.

Supported source line: `0.1.114` public snapshot. Hardware compatibility still
depends on the AIUI host, glasses firmware, and the specific BLE peripheral.
