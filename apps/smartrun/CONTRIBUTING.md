# Contributing

Issues, redacted compatibility reports, documentation fixes, and reproducible
test cases are welcome.

Code contributions are temporarily limited to maintainer-approved work while a
formal contributor agreement is completed. This protects the project's ability
to provide both the public noncommercial license and separate commercial
licenses. Opening a pull request does not transfer copyright or grant the
maintainer commercial relicensing rights.

Every report must:

- identify the source revision and AIUI/firmware environment;
- state whether evidence is simulation, desktop BLE, preview, or glasses;
- avoid keys, stable device IDs, raw health records, and proprietary firmware;
- keep ordinary HRS evidence separate from optional RSC evidence;
- list any remaining real-device gate honestly.
