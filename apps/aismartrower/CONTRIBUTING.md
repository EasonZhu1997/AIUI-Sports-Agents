# Contributing

Run `npm ci`, `npm test`, `npm run doctor:aiui`, `npm run contract:lint` and
`npm run preview:check` before opening a pull request. Keep parsing pure, keep
FTMS and optional HRS lifecycles isolated, and preserve the distinct milestones
discovery, connection, validation, subscription, first valid record and live.

Do not add physical control, automatic/background connection, manual CCCD writes,
MAC assumptions, private bridge commands, hardcoded endpoints or default network
traffic. Do not commit captures, firmware, generated packages, device names,
stable identifiers, health records or native error text.

Visual contributions need evidence that the contributor can license the asset for
redistribution under this project's terms. Prefer programmatic shapes and text.
Do not add vendor logos or assets copied from manuals, apps or product pages.

By submitting a contribution, you agree that the maintainer may distribute it
under PolyForm Noncommercial 1.0.0 and may offer the combined work under separate
commercial terms. A pull request itself grants no commercial license to users.
