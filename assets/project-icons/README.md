# Project icon provenance

The project owner confirmed on 2026-09-02 that the orange Run, Bike, Rower, and
Paddle artwork was owner-created and may be used directly in this Hub. None of
these files includes a Rokid, AIUI, Garmin, Bluetooth, or other third-party
logo.

Mapping:

- `smartrun-orange.png`: owner-created running figure, SHA-256
  `c22bdaa42b6399c545f7ec45714733cb087a96012e877d18b8bc6ab5f7341512`;
- `aibike-orange.png`: owner-created road cyclist, SHA-256
  `24b5a74afa74b76b4d7db1184fa88c2b54fa49973edeeab4fa8ad95910c34a62`;
- `aismartrower-orange.png`: owner-created indoor rowing machine with flywheel,
  rail, and seated rowing figure, SHA-256
  `daece02cd722f12157cdff953b910252d7584dd8feaff0a002f8decdc62934b4`;
- `aismartpaddle-orange.png`: owner-created kayak and double-bladed paddle,
  SHA-256 `38951ad25decc782f607ce79b10678477e133ac578bea185333880cbadc90d6e`.

The Rower and Paddle marks intentionally use different equipment silhouettes.
The Rower icon must never show a boat, water, or paddle, and the Paddle icon must
not be presented as evidence for AISmartRower.

These marks identify their corresponding project pages. Their use is governed
by the repository `TRADEMARKS.md`; displaying a mark does not prove source
publication, AIX delivery, hardware validation, platform review, endorsement,
or commercial authorization.
