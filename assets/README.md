# Public visual assets

The following project-produced documentation assets are published under the repository root Apache-2.0 license:

- `brand/hero.svg` and `brand/logo.svg`;
- `dialogue-comics/aiui-sports-agents-friendly-future-comic.png`;
- `architecture/aiui-sports-agents-home-overview-handdrawn-v3.png` and
  `architecture/aiui-sports-agents-technical-architecture-handdrawn.png`.

The comic and architecture image explain the relationship among Run, Bike, Rower, the shared Hub, and the evidence gates. They are not screenshots, benchmark evidence, device certification, or a statement of Rokid/AIUI endorsement. Product and protocol names inside them are descriptive compatibility references; third-party marks remain with their owners.

Only files explicitly tracked in Git are part of this public asset set. Drafts and unrelated local artwork in the same workspace are not published by this statement.

The project owner confirmed that the orange Run, Bike, and Paddle artwork under
`project-icons/` is owner-created and authorized for direct use in this Hub.
The orange indoor Rower SVG was drawn specifically for this Hub because no
matching orange Rower artwork existed; Rower and Paddle deliberately use
different equipment shapes.
Their use is governed by `TRADEMARKS.md`, and the detailed provenance and
non-evidence boundary is recorded in `project-icons/README.md`.
