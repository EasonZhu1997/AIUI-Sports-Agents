# 公开源码与许可边界

AIUI Sports Agents 采用“白名单公开”而不是“把现有工作目录整体推上去”。当前评测与治理 Hub 是 Apache-2.0 开放源代码；未来独立应用源码计划采用 PolyForm Noncommercial 与书面商业许可，属于 source-available。准备公开任何内容时，必须先判断文件的权利主体、许可层、第三方边界和证据类型，再决定能否进入快照。

## 三条独立审核链

| 内容 | 典型例子 | 进入公开仓库的条件 | 许可证结论 |
| --- | --- | --- | --- |
| Hub 自有代码与文档 | Registry、评测、验证工具、契约、文章 | 作者/贡献者有权按 Apache-2.0 授权；通过密钥、隐私与构建物检查 | 按根目录 Apache-2.0 提供，允许合规商用 |
| 未来应用原创源码 | Run/Bike/Rower 算法、状态机、产品 UI 与构建工程 | 位于独立应用仓；准确记录法定授权主体；官方 PolyForm 文本、商业入口和 CLA 权利链完整 | 免费路径限 PolyForm 允许的非商业目的；商用须另签书面许可 |
| 第三方代码与资产 | 依赖源码、字体、图标、GIF、音频、样例数据 | 来源、版本、许可证、修改和再分发条件全部登记 | 保持第三方原许可证，不自动变成 Apache-2.0、PolyForm 或商业可再许可内容 |
| 硬件测试证据 | 设备照片、录屏、日志、结果卡 | 与版本绑定；获得必要同意；脱敏；公开范围单独确认 | 默认仅作查看证据，不推定可再使用 |

一个文件不能因为“技术上需要”就跳过权利和隐私检查。无法证明来源或授权时，从发布白名单排除，并用可再生成的占位、合成夹具或文字摘要代替。

## 默认允许的内容

- 本项目原创且有来源记录、并已明确归入 Hub 或应用许可层的源码、测试和文档；
- 从原创脚本确定性生成、且输入同样可公开的测试夹具；
- 只包含必要字段的合成 BLE/IMU 数据；
- 经过审核的依赖清单、协议引用和兼容性说明；
- 绑定 commit/版本、经过脱敏的结果摘要。

## 默认排除的内容

- `.env`、密钥、令牌、证书、签名文件、账号或服务器配置；
- `node_modules`、缓存、临时目录、数据库、编辑器状态、崩溃转储；
- AIX/APK、安装包、构建目录、预览输出和未经批准的二进制发布物；
- 私有仓库完整 Git 历史、内部 issue 导出、聊天记录和工作交接材料；
- 原始 BLE/IMU 包、真实位置/轨迹、设备地址、序列号、账号标识和完整现场日志；
- 未经权利审核的厂商手册、SDK、固件、截图、品牌素材、字体、音乐、图片、GIF 和视频；
- 仅因“网上可下载”“AI 生成”“用于研究”或“已买设备”而被误认为可再许可的内容。

## 干净快照流程

1. **冻结来源**：记录准备公开的源 commit、项目版本和负责人。
2. **建立白名单**：从要公开的具体文件列表开始，不从排除列表反推。
3. **重建目录**：复制允许的源文件到新的暂存树，不携带原仓库 `.git`。
4. **检查来源与许可层**：确认原创与第三方边界，记录准确权利主体、Apache/PolyForm 作用域、商业再许可权与必要 CLA，并更新 `THIRD_PARTY_NOTICES.md`。
5. **检查敏感信息**：扫描密钥、凭据、个人数据、设备标识、绝对本机路径和内部 URL。
6. **检查生成物**：确认包、缓存、日志、大文件和本地证据没有混入。
7. **从暂存树验证**：仅使用暂存树重新安装公开依赖、运行测试和构建；不能借用原工作区缓存证明可复现。
8. **绑定证据**：应用源码用 [`SOURCE_DISTRIBUTION_APPROVAL.json`](./SOURCE_DISTRIBUTION_APPROVAL.md) 绑定版本、许可方、权利审查、Git 修订与候选 manifest；包另记录必要的 UUID/SHA-256 和开放门。
9. **人工复核**：安全/隐私、第三方、许可作用域和发布负责人分别签核适用项；应用源码缺少准确法定授权主体时不得标记为可发布。
10. **单独授权发布**：检查通过只表示“可发布候选”，不自动创建仓库、推送、上传、安装或部署。

## 外部项目与总项目的关系

总项目可以用链接和元数据索引 Run、Bike、Rower、Paddle、Rider，但链接、项目卡和 Registry 计划不会改变外部项目的许可证，也不会自动授予尚未发布的应用源码。未来应用源码应保留在独立仓库；若确需复制文件，每个文件都必须重新走上述白名单、权利主体、许可作用域、来源和测试流程。

共同评测规范可以复用，但不同运动的专项分数不能合并成没有意义的跨运动排名。公开名称、兼容性和证据必须准确，不得暗示平台或设备厂商背书。

## 发布物不是源码快照

源码可公开不代表 AIX/APK 可直接分发。每个二进制发布物都要按实际包内容重新检查第三方许可、包内文件、版本、UUID、SHA-256、大小、Reader/Preview 与真机门。未完成的门必须写在发布说明中。
