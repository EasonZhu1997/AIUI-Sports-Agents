# 公开与发布检查清单

本清单用于源码首次公开、正式 tag 和二进制发布候选。勾选完成表示候选已被检查，不表示授权执行推送、上传、安装、签名或部署。

## A. 范围与来源

- [ ] 记录源 commit、项目版本、目标内容和负责人。
- [ ] 从明确白名单建立新的暂存树，没有复制原私有仓库 `.git`。
- [ ] 每个文件可归类为自有作品、已登记第三方内容或已授权证据。
- [ ] 许可证、版权、NOTICE 与商标说明和实际暂存内容一致。
- [ ] 没有来源不明的代码、图片、字体、音频、视频、GIF、数据或二进制。

## B. 敏感信息与隐私

- [ ] 扫描密钥、令牌、证书、签名材料、内部 URL 和本机绝对路径。
- [ ] 没有账号、设备地址/序列号、位置、轨迹、通讯内容或旁人影像。
- [ ] 日志、截图、录屏和照片已最小化、脱敏并确认公开权利。
- [ ] 新权限、存储、日志和网络行为已有数据流说明。
- [ ] 默认离线；每项上传都有具体目的的显式 opt-in、关闭与删除路径。

## C. 源码复现

- [ ] 在干净暂存树安装依赖，没有借用原工作区 `node_modules` 或缓存。
- [ ] 记录所有实际运行命令、工具版本和退出结果。
- [ ] 自动化测试包含正常、错误、缺失、断流和生命周期边界。
- [ ] 失败、跳过和不适用项没有被隐藏。
- [ ] README/登记信息中的构建与测试步骤能由第二人复现，或已明确单人限制。

## D. 包与证据

- [ ] 若发布包：文件名、语义版本、locale、UUID 与 SHA-256 已记录。
- [ ] 包内容已单独审计，不含测试、缓存、日志、旧包、密钥或多余资产。
- [ ] Reader/Preview/Craft/真机结论按 L2–L5 分开，没有越级声明。
- [ ] L4 结果绑定眼镜型号、固件、AIUI host build 和相同包身份。
- [ ] L5 结果包含参考设备、样本、误差分布、失败和排除规则。
- [ ] 发布说明列出所有仍开放的真机、兼容性、隐私和第三方门。

## E. 运动专项门

- [ ] Run：步频/配速/距离与误步、静止、隐藏恢复分别验证。
- [ ] Bike：数据来源优先级清晰；无真实功率时保持 unavailable；停车不虚增。
- [ ] Rower：只订阅 FTMS Rower Data 和可选 HRS；没有发现、订阅或写入 `0x2AD9`。
- [ ] 跨运动只比较共同方法；专项分不合并成跨运动总排名。

## F. 人工签核

- [ ] 对应运动维护者确认实现范围。
- [ ] 证据审阅者确认等级和声明。
- [ ] 安全/隐私审阅者确认适用项。
- [ ] 发布负责人确认暂存内容与最终候选完全相同。
- [ ] 获得一次明确的发布决定；没有把“请准备”“本地验证”当成发布授权。

## 发布后

- [ ] 公布最终 tag、hash、版本和已知限制。
- [ ] 保留签核记录与不可变结果索引。
- [ ] 建立安全报告入口和回滚/撤回说明。
- [ ] 如果最终内容与已审候选不同，停止发布并从相应检查项重新开始。
